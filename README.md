# Airelibre Restaurant & Bar — Website

Sitio estático (HTML + CSS + JS, sin build). Abrir `index.html` o servir la carpeta.

- `index.html` — página completa; el menú y las bebidas están en los arrays `MENU`, `HH` y `BAR` al final del archivo.
- `img/` — fotos y logo.
- `deploy.sh` — sube el sitio al VPS (lo sirve el Caddy del Portal DCR en https://airelibre.147-93-5-74.sslip.io).
